# Scratch 清單實作（Scratch_Array_Command）

讓國中學生動手操作 Scratch 的清單積木，認識「新增、刪除、修改、查詢」四類指令的互動練習網頁。

## 題目

| 題號 | 內容 | 配分 |
|---|---|---|
| 1–5 | 新增：添加、插入（最前面、中間、最後面、空清單） | 每題 4 分 |
| 6–9 | 刪除：刪除第幾項、最後一項、所有項目 | 每題 4 分 |
| 10–12 | 修改：替換第幾項、最後一項 | 每題 4 分 |
| 13–20 | 查詢：第幾項是誰、項目編號（含重複名字）、長度、是否包含 | 每題 4 分 |
| 21–24 | 認識指令：從「購物車」積木中選出新增／刪除／修改／查詢指令 | 每題 5 分 |

滿分 100 分。

## 操作方式

- 把左邊的積木拖到作答區，或點一下放入；在積木的白色欄位輸入文字或數字，再按「執行」。
- 判定分兩階段：先檢查作答區的積木和欄位，正確後再檢查執行結果。
- 清單操作完全照 Scratch 的規則，例如超出範圍不會改變清單、找不到時項目編號回傳 0。

## 計分規則

- 每答錯一次扣 1 分，點開提示扣 1 分（每題只扣一次），答對最低 2 分；沒答對 0 分。
- 「下一題」隨時可以按；跳過的題目可以點上方題號回去作答。
- 第 1–20 題全部答對，才能進入第 21–24 題；進入後就不能再回到第 1–20 題。

## 上傳成績到 Google 試算表

直接開啟 `index.html`（或用 GitHub Pages）時可以正常練習，但不會上傳成績。
要上傳成績，請用 Google Apps Script 網頁應用程式開啟：

1. 建立一份 Google 試算表，選「擴充功能 → Apps Script」。
2. 把 `Code.gs` 的內容貼到 Apps Script 的 `Code.gs`。
3. 新增 HTML 檔，命名為 `index`，貼上 `index.html` 的內容。
4. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分選「我」，存取權選「（學校網域）中的所有人」。
5. 把部署後的網址給學生，學生用學校帳號開啟。

每完成 5 題（第 5、10、15、20 題答對時）以及測驗結束時，會自動上傳一次成績到試算表的「成績」工作表。
每位學生一列，記錄上傳時間、帳號、完成題數、總分和每題得分；只有分數大於或等於原本的總分才會覆蓋。
